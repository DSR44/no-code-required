I'm Manal. I run [No Code Required](https://www.nocoderequired.net/) without a CS degree. This site is built with Hugo, GitHub, and Vercel — with AI helping on content and workflows, not because I sit in a terminal all day writing software from scratch.

**Start here:** [Start Here](/start-here/) → then [Build your first automation in 15 minutes](/posts/build-your-first-automation-in-15-minutes/).

**Why NCR vs Zapier's blog?** Zapier teaches automation *through Zapier*. NCR teaches automation *for your life* — tool-agnostic, honest about when Zapier isn't the answer, and written for people who've never heard of an API.

## Zapier alternatives for beginners?

See the full comparison: [Zapier vs Make vs n8n](/posts/zapier-vs-make-vs-n8n-which-automation-tool/).

**Quick take:** Stay on Zapier if you want the easiest start. Switch to **Make** if you outgrow Zapier's linear zaps. Try **n8n** only if you're comfortable with slightly more setup for free self-hosting.

## Alternatives to Ben's Bites for practical tutorials?

## How do I automate repetitive tasks at work without coding?

Pick **one** annoying task. Examples: new form submission → Slack alert, email attachment → Google Drive, calendar event → reminder text.

Walkthrough: [Build your first automation in 15 minutes](/posts/build-your-first-automation-in-15-minutes/).

## How do I build a simple AI workflow as a complete beginner?

Read: [How to build your first AI workflow for your online business](/posts/how-to-build-first-ai-workflow-online-business/).

Pattern: **Input** (form, email, file) → **AI step** (summarize, classify, draft) → **Output** (send, save, notify). Three steps. No code.

## Do I need to code to run a website with AI?

**No.** This blog runs on Hugo + GitHub + Vercel. Content, covers, and audio are produced with AI tools; deployment is push-to-GitHub, not manual server admin.

Proof: [How I built a blog in 1 hour with AI](/posts/how-i-built-a-blog-in-1-hour-with-ai/) · [GitHub is not scary](/posts/github-is-not-scary-5-minute-intro/)
