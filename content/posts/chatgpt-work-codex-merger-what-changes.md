If you've been using ChatGPT for everyday tasks — drafting emails, brainstorming content, organizing ideas — the latest round of OpenAI changes might feel like someone rearranged your kitchen while you were sleeping. **ChatGPT Work just absorbed Codex**, Atlas is getting the axe, and there's a new model (GPT-5.6) layered on top. If you're not a developer, the immediate question is simple: does any of this matter to me? The answer is yes, but probably not the way the press release suggests. If you've been following the [agent consolidation trend](/posts/openai-agent-consolidation-what-changes/), this is OpenAI's version of "one app to rule them all."

## What actually changed (no jargon)

Here's the plain version. OpenAI had three things: regular ChatGPT (the one you type into), Codex (the coding-focused tool), and Atlas (a dedicated browser). Now it has two: **ChatGPT Work** and **ChatGPT Classic**.

ChatGPT Work is the new default on desktop. It's designed for longer, more involved tasks — the kind that take minutes or hours rather than seconds. Codex still exists as a "view" inside ChatGPT Work, but it's no longer a separate product. Think of it like how Google Docs absorbed the drawing tool — it's still there, but you don't open a different app to use it.

ChatGPT Classic is what the old ChatGPT became. You access it through a "quick chat" button on desktop or a dropdown on mobile. It's the conversational version — ask a question, get an answer, done.

Atlas, the dedicated web browser OpenAI launched less than nine months ago, is being sunset entirely. If you were using it, the Chrome extension is the replacement.

## The pricing reality check

This is where it gets real for non-coders. ChatGPT Work uses a credit system, and credits burn faster than you'd expect on complex tasks. Plans go up to $100 per month, with [built-in usage limits](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-freegopluspro) that vary by tier.

The key distinction: **ChatGPT Work tasks use more credits than regular chat.** OpenAI says this openly — "complex tasks may use more of your plan's included usage." For non-coders, this means a workflow that runs for an hour researching, compiling, and formatting could eat through a meaningful chunk of your monthly allowance.

## What the unlimited text chats change means for you

Here's the good news that got buried in the headlines: OpenAI is giving ChatGPT free and Go users **unlimited text chats** starting next week, according to reporting from [The Verge](https://www.theverge.com/ai-artificial-intelligence/976239/openai-chatgpt-free-go-text-chats) and [TechCrunch](https://techcrunch.com/2026/08/06/openai-brings-unlimited-chatgpt-text-chats-to-free-users/). This is a direct response to competition from Google's Gemini and Anthropic's Claude, both of which have been eating into OpenAI's user base.

For non-coders, this means the conversational side of ChatGPT — the Classic mode — just became essentially free forever. You can ask questions, draft emails, and brainstorm without watching a meter. The catch? **ChatGPT Work tasks still cost credits.** So if you want the agent-style workflows that run in the background, you're still paying. The unlimited change only applies to the quick chat experience.

Think of it like a restaurant: the bread basket is now unlimited, but the entrée still costs money. If your workflow is mostly conversational, you're in great shape. If you need the longer, automated tasks, budget accordingly.

## How to actually use ChatGPT Work (step-by-step)

Here's what I'd do if I were you. Open ChatGPT on desktop. You'll see **ChatGPT Work** as the default view — that's the new one. Click the "quick chat" button if you want the old conversational experience.

For a task in Work mode, try this: "Research the top five project management tools for small teams, compare their pricing, and format it as a table with pros and cons." That's the kind of multi-step job Work is built for. Watch the credit counter in the bottom right — it'll show you how much that task costs in real time.

If you're on a free or Go plan, stick with Classic for now. The unlimited text chats mean you can do 90% of what most non-coders need without touching the credit system at all.
